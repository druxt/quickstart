# Druxt Quickstart

A fully decoupled starter-kit: **Drupal 11** (backend, JSON:API) + **Nuxt 2** (frontend, via [DruxtSite](https://druxtjs.org)).

If you opened this in a dev container / DevPod, setup already ran automatically (`npm install` at the repository root provisions the whole stack: frontend deps, Composer, a local Drupal site with SQLite, and OAuth for authenticated editing).

| Service        | URL                                 |
| -------------- | ----------------------------------- |
| Drupal backend | http://127.0.0.1:8888               |
| Nuxt frontend  | not started yet - see the next step |

If setup hasn't run yet (e.g. you cloned this manually), run `npm run setup` in a terminal first.
